# 🚀 Prompts Manager

Aplicação web para **gerenciar e organizar prompts de IA**, permitindo que usuários encontrem, salvem e reutilizem prompts de forma prática e eficiente.

🔗 Acesse: https://prompts-manager-tawny.vercel.app/

---

## 📝 Sobre o projeto

O **Prompts Manager** é uma plataforma pensada para facilitar o uso de inteligência artificial no dia a dia, centralizando prompts em um único lugar.

A aplicação permite que usuários:

- Criem prompts para reutilizar  
- Busquem por prompts através de palavras específicas  
- Organizem prompts facilmente

A ideia principal é evitar que prompts úteis se percam e criar um ambiente prático para evolução no uso de IA.
